# QA API Trainer

Веб-тренажёр для обучения тестированию REST API.

**[Открыть тренажёр →](https://punk-and-babka.github.io/qa-api-trainer/)**

Слева — эталонная спецификация, посередине — клиент запросов, справа — ответ.
Сервер поддельный и работает прямо во вкладке браузера: сети нет, запросы
никуда не уходят. В нём намеренно оставлено десять дефектов — мест, где
поведение расходится со спецификацией. Их и нужно найти.

Отличие от Postman в том, что здесь известен правильный ответ: спецификация —
эталон, дефекты описаны списком, поэтому тренажёр может отличить настоящее
расхождение от ложной тревоги.

> Спойлер: приложение целиком клиентское, поэтому каталог дефектов попадает в
> бандл вместе с остальным кодом. Если хочешь пройти тренажёр честно — не
> заглядывай в `src/mock-api/scenarios/users.bugs.js`.

## Что внутри

- **Задания и справка** — восемь заданий с подсказкой, каким инструментом их
  удобнее решать; у каждого раздела своя шпаргалка по кнопке «?».
- **Конструктор запросов** — метод, путь с query, тело в JSON, история с
  восстановлением запроса по клику.
- **Проверка по схеме** — валидация тела ответа по JSON Schema (`ajv`), схемы
  написаны по спецификации, а не по фактическому поведению сервера.
- **Панель Tests** — настоящий JavaScript с объектом `pm`, как в Postman:
  `pm.test`, `pm.expect`, `pm.response`, `pm.environment`.
- **Переменные окружения** — подстановка `{{имя}}` в путь и тело, цепочки
  запросов через `pm.environment.set`.
- **Баг-репорты** — форма со сверкой по каталогу и счётчиком найденного.

Прогресс, тестовый скрипт, переменные и раскладка колонок сохраняются в
`localStorage` и переживают перезагрузку страницы.

## Запуск локально

```
npm install
npm run dev
```

Откроется `http://127.0.0.1:5173/`.

## Стек

React + Vite, чистый JavaScript без TypeScript, обычный CSS без UI-китов.
Состояние — `useState`, без внешних менеджеров. Из зависимостей только
`react`, `react-dom`, `vite`, `@vitejs/plugin-react`, `ajv` и `ajv-formats`:
подсветка JSON, мини-`expect` вместо chai и всё остальное написаны вручную.

Устройство проекта и принятые решения подробно разобраны в
[CLAUDE.md](CLAUDE.md).
